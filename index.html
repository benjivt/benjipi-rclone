benjipi rclone

benjipi rclone is a personal, non-commercial Google OAuth client used by one person (Benjamin Adjepong) to back up his own home server to his own Google Drive with rclone.

It requests only the drive.file scope, so it can see and change only the files that it creates itself. It cannot read anything else in Google Drive.

It is not offered to, or intended for, anyone else.
